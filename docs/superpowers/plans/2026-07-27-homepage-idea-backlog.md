## 3 — One Law question on the homepage (deferred, B+)

**The idea.** Comfort opens every street conversation the same way. Put that one
question on the homepage, under the hero:

> **Have you ever told a lie?** → *Yes* / *No*

Either answer lands the same beat — *"So what does that make you?"* — then:
**"Five more questions. Take the test."**

**Why it scores well.** It is the method's actual opening move, not a novelty. It
claims nothing about the reader, it asks. It is interactive in a way a link list
is not. And it converts the visitor who will not commit to a six-question test but
will answer one.

**Why it is deferred, not rejected.** It conflicts with a requirement the owner
set explicitly: keep the new visitor's CTA simple and unconfusing. Putting a
second interactive ask beside the gold **Take the test** button gives a first-time
reader two things to decide between, which is the problem we were solving.

**The condition that would unblock it.** It only works if the question *replaces*
the CTA as the way into the test — i.e. answering it IS starting the test, and the
gold button either goes or becomes secondary. That is a bigger change to the front
door than it first appears, and it should be decided on its own rather than folded
into a cleanup.

**Revisit when:** there is real traffic showing homepage → test conversion, so the
change can be judged against a number rather than an opinion.
